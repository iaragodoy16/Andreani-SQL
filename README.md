# Sistema de Gestión y Trazabilidad Logística – Andreani

Proyecto académico grupal desarrollado en la materia Ingeniería de Datos de UADE. Consiste en el diseño e implementación de una base de datos relacional para representar los procesos logísticos de distribución de medicamentos, tomando como caso de estudio a la empresa Andreani.

La solución busca centralizar la información y garantizar la trazabilidad de los productos desde su lote de origen hasta su recepción en destino.

## Objetivo
Diseñar una base de datos que permita gestionar pedidos, productos, lotes, stock, preparación, consolidación y entregas, asegurando la integridad de la información y facilitando el seguimiento de las operaciones.

##  Funcionalidades principales
- Gestión de pedidos, productos, lotes y stock.
- Control de preparación y consolidación de pedidos.
- Seguimiento de cajas y entregas.
- Trazabilidad completa de medicamentos por lote.
- Consultas de negocio e indicadores de desempeño (KPIs).
- Validación de reglas para prevenir inconsistencias operativas.

## 🎓 Conocimientos aplicados
Modelado relacional, normalización, integridad referencial, consultas SQL, programación T-SQL, procedimientos almacenados, triggers, transacciones y análisis de indicadores de negocio.
